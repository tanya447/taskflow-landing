## Что я реализовала

- Адаптивная сетка на CSS Grid: `repeat(auto-fit, minmax(280px, 1fr))`.
- Мобильное меню на `<details>` — без JavaScript, с поддержкой клавиатуры.
- Семантическая разметка: `<header>`, `<main>`, `<section>`, `<footer>`.
- Состояния кнопок и ссылок: `:hover`, `:focus`, `:active`.
- Типографика: отступы через `rem`, `line-height` для читаемости.
- Плейсхолдеры вместо изображений — фокус на структуре и адаптивности.

## Технологии

- CSS3 (Flexbox, Grid)
